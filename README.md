# Emotion Detection Web Application

A Flask-based web application that analyzes text and detects the underlying emotions (Joy, Anger, Disgust, Sadness, and Fear) using the embedded Watson AI libraries.

## Features
* Connects to the Watson NLP Emotion Predict API.
* Extracts and formats confidence scores for multiple emotions.
* Calculates the dominant emotion dynamically.
* Handles blank or invalid inputs with custom error messages.
* Includes comprehensive unit tests.
* Passes static code analysis (Pylint 10/10).
